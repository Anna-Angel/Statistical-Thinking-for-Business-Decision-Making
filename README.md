# Statistical-Thinking-for-Business-Decision-Making
NBA Salary Predictions Model

The dataset used for this project was a dataset that combined the NBA player salaries and NBA player points datasets for 2021, both retrieved from ESPN. When the dataset was combined and cleaned initially, there were 35 columns and 513 columns. We were interested in seeing how player performance related to pay.

The Assignment 2 folder contains the trimmed down dataset we used for our models.

The Assignment 3 folder contains an excel file with descriptive statistics and data visualization.

The Assignment 4 folder contains an excel file with probability and distribution models.

The Assignment 5 folder contains an excel file with our hypothesis testing and confidence intervals.

The Assignment 6 folder contains an excel file with regression modeling.
